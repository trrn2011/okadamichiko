# 産後ドゥーラ 岡田みちこ ウェブサイト 要件定義

## 1. プロジェクト概要

### 1.1 目的
認定産後ドゥーラ 岡田みちこの個人サービスサイトを制作し、サービス内容の周知と問い合わせ獲得を実現する。

### 1.2 ターゲットユーザー
- 産前産後の母親（妊娠中〜産後数ヶ月）
- そのご家族（パートナー、祖父母など）
- 対象エリア: 大田区およびその周辺地域

### 1.3 ゴール
- サービス内容・料金・資格を分かりやすく伝える
- Instagram DMへの問い合わせ（CTA）につなげる
- 信頼感・安心感を与えるデザイン

---

## 2. サイト構成

シングルページ構成（LP形式）。以下のセクションで構成する。

| # | セクション | 目的 |

| 1 | ヒーロー | 第一印象・自己紹介 |
| 2 | お祝いメッセージ | 共感・信頼構築 |
| 3 | 経歴 | 信頼性・実績 |
| 4 | サポート時間 | 実務情報 |
| 5 | ご利用料金 | 価格情報 |
| 6 | 得意なこと | 強み・差別化 |
| 7 | 保有資格 | 専門性・信頼性 |
| 8 | サポート内容 | サービス詳細 |

| 10 | 助成金・保険 | 付加価値・安心感 |

## 3. 機能要件

### 3.1 ページ全体
- シングルページ（index.html 1ファイル）
- 静的HTMLサイト（サーバーサイド処理なし）
- 外部CSSファイル（style.css）で管理

### 3.2 ヒーローセクション
- 挨拶テキスト「こんにちは」
- 肩書き「認定産後ドゥーラ」
- 名前「岡田みちこ」
- CTAボタン「ご連絡はこちら」→ Instagram外部リンク

### 3.3 お祝いメッセージ
- 見出し「ご懐妊・ご出産おめでとうございます」
- 共感メッセージ本文（3段落）
- 最終段落は強調表示

### 3.4 経歴
- 箇条書き形式（5項目）
- ドット付きリスト表示

### 3.5 サポート時間
- 営業日: 月〜金
- 営業時間: 9:00〜17:00
- 注意書き: その他時間帯は要相談

### 3.6 ご利用料金
- 産後プランニング: 2,000円/1回
- ドゥーラサポート: 3,000円/1時間
- 往復交通費別途
- お支払い方法: 現金、銀行振り込み

### 3.7 得意なこと
- 4つのカード形式で表示
- 各カードに絵文字アイコン + 説明テキスト

### 3.8 保有資格
- チェックマーク付きリスト
- 保育士 / 幼稚園教諭 / 救命救急技能認定 / 放課後児童支援員

### 3.9 サポート内容
- 6つのサービス項目をグリッド表示
- 注意書き3点

### 3.10 ご利用の流れ
- 4ステップ（お問い合わせ → ご連絡 → 初回ご訪問 → サポート開始）
- ステップ間に矢印（モバイルでは非表示）
- CTAボタン「お申し込みはこちら」→ Instagram外部リンク

### 3.11 助成金・保険
- 助成金対象自治体: 大田区
- 加入保険: ドゥーラ賠償責任保険

### 3.12 フッター
- 著作権表示「© 2026 認定産後ドゥーラ 岡田みちこ」

## 4. 非機能要件

### 4.1 デザイン
- やわらかいピンク水彩画風のデザイン
- フォント: Noto Sans JP（Google Fonts）
- 水彩風のぼかしブロブ装飾（CSSのみで実現）
- カード・ボタンにホバーアニメーション
- フェードインアニメーション

### 4.2 レスポンシブ対応
- モバイルファースト
- ブレークポイント: 640px / 768px
- モバイルでの最適化:
  - ステップ間矢印の非表示
  - 料金カードのフル幅表示
  - セクション余白の縮小

### 4.3 パフォーマンス
- 画像なし（テキスト + CSS装飾のみ）
- 外部依存: Google Fonts のみ
- JavaScript なし

### 4.4 ブラウザ対応
- モダンブラウザ（Chrome, Safari, Firefox, Edge 最新版）
- スマートフォンブラウザ（iOS Safari, Android Chrome）

### 4.5 ホスティング
- 静的サイトホスティング（GitHub Pages 等で対応可能）
