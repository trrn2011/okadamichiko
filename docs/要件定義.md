# 産後ドゥーラ 岡田みちこ ウェブサイト 要件定義

最終更新: 2026-10-04（現行の index.html / style.css の内容に合わせて更新）

## 1. プロジェクト概要

### 1.1 目的
認定産後ドゥーラ 岡田みちこの個人サービスサイトを制作し、サービス内容の周知と問い合わせ獲得を実現する。

### 1.2 ターゲットユーザー
- 産前産後の母親（妊娠中〜産後数ヶ月）
- そのご家族（パートナー、祖父母など）
- 対象エリア: 大田区・港区・品川区（その他エリアは要相談）

### 1.3 ゴール
- サービス内容・料金・資格・空き状況を分かりやすく伝える
- Instagram DM またはメールでの問い合わせ（CTA）につなげる
- 信頼感・安心感を与えるデザイン

## 3. 機能要件

### 3.1 ページ全体
- シングルページ（index.html 1ファイル）
- 静的HTMLサイト（サーバーサイド処理なし）
- 外部CSSファイル（style.css）で管理
- 画像: profile.jpg（プロフィール）、work.jpg（サポートの様子）

### 3.2 ヒーローセクション
- プロフィール写真2枚（円形）
- 挨拶テキスト「こんにちは」
- 肩書き「認定産後ドゥーラ」
- 名前「岡田みちこ」
- CTAボタン2つ（左から順に）
  - 「メールで問い合わせ」→ mailto リンク（塗りつぶしのメインボタン）
  - 「Instagram DMはこちら」→ Instagram外部リンク（白抜きボタン）

### 3.3 ご予約状況
- Google Calendar API（公開カレンダー + APIキー）からイベントを取得し、月カレンダーを描画
- 表示範囲: 今月・来月の2ヶ月（前後ボタンで切り替え）
- 各日に午前（9:00〜12:00）・午後（13:00〜19:00）の2枠を表示
- カレンダー上に「空き」イベントがある枠を予約可能（○）、それ以外を予約不可（✕）として表示
- 当日はハイライト表示
- API取得に失敗した場合は「お問い合わせください」のエラーメッセージを表示
- 注意書き「＊最新の空き状況はお問い合わせください。」

### 3.4 お祝いメッセージ
- 見出し「ご懐妊・ご出産おめでとうございます」
- 共感メッセージ本文（3段落）
- 最終段落は強調表示

### 3.5 経歴
- 箇条書き形式（5項目）
- タイムライン（ドット付き）表示

### 3.6 得意なこと
- 4つのカード形式で表示
- 各カードに絵文字アイコン + 説明テキスト

### 3.7 保有資格
- チェックマーク付きリスト
- 保育士 / 救命救急技能認定 / 放課後児童支援員 / 離乳食アドバイザー

### 3.8 サポート内容
- 5つのサービス項目をグリッド表示（日常の家事 / 赤ちゃんのお世話 / 検診などのお出かけ同行 / 上の子のお世話 / お買い物代行）
- 注意書き1点（送迎・お出かけ同行時の交通費はご利用者様負担）

### 3.9 ご利用の流れ
- 4ステップ（お問い合わせ → ご連絡 → 初回ご訪問 → サポート開始）
- ステップ間にコネクター（モバイルでは非表示）
- セクション末尾にヒーローと同じCTAボタン2つ

### 3.10 サポート時間・訪問エリア
- 営業日: 月・火・木・金
- 営業時間: 9:00 — 19:00
- 注意書き: その他時間帯は要相談
- 訪問可能エリア: 大田区・港区・品川区
- 注意書き: その他エリアも要相談

### 3.11 ご利用料金
- 産後プランニング: 2,000円/1回
- ドゥーラサポート: 3,300円/1時間（最低2時間から、強調カード表示）
- 往復交通費別途
- お支払い方法: 現金、銀行振り込み、PayPay
- 予約変更・キャンセル規定: 前日17時以降の予約変更・キャンセルは1時間分の料金をキャンセル料として徴収

### 3.12 助成金・保険
- 助成金対象自治体: 大田区・港区・品川区
- 加入保険: ドゥーラ賠償責任保険

### 3.13 フッター
- 著作権表示「© 2026 認定産後ドゥーラ 岡田みちこ」

## 4. 非機能要件

### 4.1 デザイン
- 温かみのあるアースカラー（クリーム・ローズ・テラコッタ・ブラウン・セージ）のパレット
- フォント: Shippori Mincho B1（見出し）/ Zen Kaku Gothic New（本文）（Google Fonts）
- ヒーローにぼかしオーブ装飾（CSSのみで実現）
- カード・ボタンにホバーアニメーション
- `prefers-reduced-motion` に対応（アニメーション抑制）

### 4.2 レスポンシブ対応
- モバイルファースト
- ブレークポイント: 560px / 768px
- モバイルでの最適化:
  - ステップ間コネクターの非表示
  - 料金カード・各種カードのフル幅表示
  - カレンダーのセル・記号サイズ縮小
  - セクション余白の縮小

### 4.3 パフォーマンス
- 画像2枚（profile.jpg / work.jpg）
- 外部依存: Google Fonts、Google Calendar API
- JavaScript: ご予約状況カレンダーの描画のみ（インライン）

### 4.4 ブラウザ対応
- モダンブラウザ（Chrome, Safari, Firefox, Edge 最新版）
- スマートフォンブラウザ（iOS Safari, Android Chrome）

### 4.5 ホスティング
- 静的サイトホスティング（GitHub Pages）
